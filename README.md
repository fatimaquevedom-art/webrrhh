# Nexus RRHH - Portal y Consultoría de Recursos Humanos

Sitio web corporativo y portal de empleo desarrollado con **HTML5, CSS3 moderno y JavaScript vanilla**. Diseñado para desplegarse fácilmente en **Vercel** conectado a **GitHub**.

## 🚀 Características
- **Diseño Moderno & Responsivo**: Adaptable a celulares, tablets y computadoras de escritorio.
- **Buscador y Filtros de Vacantes**: Filtrado en tiempo real por departamento (Tecnología, RRHH, Ventas, Finanzas) y búsqueda por texto.
- **Modal de Postulación Dinámica**: Formulario interactivo para aplicar a ofertas específicas o enviar candidatura espontánea.
- **Formulario de Contacto B2B**: Para empresas interesadas en contratar servicios de consultoría y gestión de talento.
- **Cero dependencias pesadas**: Carga instantánea, sin necesidad de instalación de paquetes ni compilación previa.

## 📦 Estructura de Archivos
```
├── index.html        # Estructura principal y secciones de la web
├── styles.css        # Estilos, variables CSS, layout responsive y animaciones
├── script.js         # Lógica interactiva, filtros, modal y notificaciones
└── README.md         # Documentación del proyecto
```

## 🌐 Cómo desplegar en Vercel
1. Sube estos archivos a tu repositorio de GitHub `webrrhh`.
2. Ingresa a [Vercel](https://vercel.com) e inicia sesión con tu cuenta de GitHub.
3. Haz clic en **Add New...** > **Project**.
4. Selecciona tu repositorio `webrrhh` y haz clic en **Deploy**.
5. ¡Listo! Vercel creará tu enlace web público gratuito en cuestión de segundos.
